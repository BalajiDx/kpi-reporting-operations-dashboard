# KPI Reporting & Operations Dashboard

Monthly operational KPI reporting for a content-services operation (data conversion, academic editing, typesetting):
a **formula-driven Excel KPI workbook** with a team scorecard and a data-quality checklist, and the same KPIs laid out as a
**Power BI** dashboard.

> **Synthetic data.** Jobs, staffing and escalations were generated by `01. Dataset/generate_dataset.py` (seed 61);
> client names are invented. No real company data is used. The project reflects the kind of monthly operations and
> client-delivery reporting I work on as a Project Management Executive, rebuilt on made-up data so it can be shared.

## What is in it
- **Excel workbook** `02. Excel KPI Report/Operations_KPI_Report.xlsx`, built by `build_kpi_workbook.py`:
  - `Monthly KPIs`: 18 months x 11 KPIs, all **formulas** (COUNTIFS, SUMIFS, AVERAGEIFS, EOMONTH), RAG colours against targets, 2 charts
  - `Team Scorecard`: pick a month from a drop-down; each team vs target and vs the previous month (INDEX/MATCH)
  - `Targets` (editable inputs), `KPI Definitions`
  - `DQ Checklist`: 11 automated checks (SUMPRODUCT/COUNTIFS) + the monthly manual checklist
  - 71,669 formulas, recalculated with **0 errors**; monthly results checked against an independent pandas calculation
- **Power BI** layout: 2 report pages + data model, DAX measures, build guide

## Key findings
| # | Finding |
|---|---|
| 1 | Over 18 months, **83.0%** of 17,640 jobs were delivered on time (target 90%), first-pass quality was **97.1%** and turnaround averaged **3.9 days**. |
| 2 | Performance drops every academic peak (Sep-Nov, Mar). The worst month was **Oct-24** at **66.2%** on time. |
| 3 | In Sep-Nov 2024 **Typesetting** ran at **78%** of planned staff and its on-time rate fell to **60.0%** (vs 91.2% in normal months). Escalations peaked at **30** in Oct-24. |
| 4 | Data Conversion has the lowest first-pass quality (**93.0%**) because its large jobs carry more QA errors. |

**Suggested actions (for the synthetic case):** plan temporary typesetting capacity before the Sep-Nov peak, track staffing vs plan
monthly as a lead indicator, and add a pre-QA check on large conversion jobs.

## Data cleaning
| Table | Issue / action | Count |
|---|---|---:|
| Jobs | Duplicate job rows removed | 60 |
| Jobs | Client names in capitals set to title case | 30 |
| Jobs | Duplicates found after fixing client names removed | 0 |
| Jobs | Missing Team filled from JobType (each job type belongs to one team) | 35 |
| Jobs | Negative Pages (sign error) made positive | 20 |
| Jobs | DeliveredDate before ReceivedDate: date cleared, Status = 'Needs review' (excluded from delivery KPIs) | 25 |
| Staffing, Escalations | No issues found (copied as is) | 0 |

## How to run
```bash
pip install pandas numpy openpyxl
cd "01. Dataset" && python generate_dataset.py && python clean_dataset.py && cd ..
cd "02. Excel KPI Report" && python build_kpi_workbook.py
```
Open the workbook in Excel; formulas calculate on open.
